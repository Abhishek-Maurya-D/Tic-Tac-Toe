# 🎮 Tic Tac Toe Game  
A simple, responsive web-based Tic Tac Toe game built using HTML, CSS, and JavaScript.  
## 🚀 Features  
> Two-player turn-based gameplay  
> Win and draw detection  
> Colored symbols for X and 0  
> Fully responsive layout for all screen sizes  
> Reset and New Game options  

## 📱 Responsive Design  
The layout adjusts to various screen sizes, making it playable on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack  
> HTML5  
> CSS3  
> JavaScript (Vanilla)
